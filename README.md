# Bryle Portfolio

Personal portfolio built with Vite, React, TypeScript, Tailwind CSS, and shadcn/ui.

## Scripts

- `npm run dev` starts the development server
- `npm run build` creates a production build
- `npm run preview` previews the production build locally
- `npm run test` runs the test suite

## Notes

- The site includes light and dark mode
- Social metadata and favicon assets live in `public/`
- Main content sections live in `src/components/`
